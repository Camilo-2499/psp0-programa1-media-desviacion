# Programa 1 · Media y Desviación Estándar (PSP0)

Solución desarrollada siguiendo estrictamente el estándar de calidad y proceso **Personal Software Process (PSP0)** del Software Engineering Institute (SEI).

## Estructura del Proyecto

* `datos/`: Archivos de prueba (Tabla 1 columnas 1 y 2, y Tabla 3 de ejemplo).
* `docs/`: Documentación por fases (planeación, diseño, pruebas, postmortem).
* `src/`: Código fuente de la solución en C# (.NET 9).
* `tests/`: Pruebas unitarias automatizadas con xUnit.
